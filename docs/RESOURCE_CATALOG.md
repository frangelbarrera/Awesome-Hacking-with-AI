# Resource Catalog

This catalog supplements the discovery tables in the README. It gives selected high-impact resources normalized metadata so readers can distinguish a canonical project link from a maintained, authorized, and appropriate deployment choice.

> **Catalog status:** entries were reviewed on **2026-08-26** from their canonical project, publisher, or official documentation. “Active” means the project was represented as maintained at that point; it is not a warranty. Verify the current release, dependency posture, license, and terms before adoption.

## Reading the Catalog

| Field | Meaning |
|---|---|
| Type | What the resource is: guide, benchmark, tool, agent, server, model, dataset, lab, or case study. |
| Maintainer / source | Canonical owner or publisher. |
| Terms | Published software/data/model license or the canonical project terms to review. |
| Status | Maintained, archived, experimental, or historical as represented by the source at review time. |
| Effects | The expected highest-impact class of capability: knowledge, read, external query, write, or execution. |
| Adoption boundary | Minimum condition for safe evaluation or use. |
| Evidence | Canonical source, official documentation, or primary paper supporting the summary. |

## Catalog Maintenance

The README is the discovery layer; this catalog is the metadata layer. New tools, agents, MCP servers, models, datasets, and labs must be added here or have equivalent recoverable metadata before they are promoted in the README. Re-review high-risk and fast-moving entries at least quarterly, mark major status changes promptly, and remove entries that lose canonical provenance or cannot meet the safety standard.
