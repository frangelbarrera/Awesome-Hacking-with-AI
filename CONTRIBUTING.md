# Contributing to Awesome-Hacking-with-AI

Thanks for your interest in contributing! This repository is a curated list of AI-powered offensive security resources.

## How to Contribute

### Adding a New Tool

1. Fork the repo and create a branch
2. Add the tool to the appropriate section in `README.md`
3. Use the existing table format and include: Tool name, Description, Key Features, and Link
4. Verify the link is working
5. Submit a pull request

### Suggesting a New Category

Open an issue with:
- The proposed category name
- A brief description of what belongs in it
- At least 3-5 tools that would fit

### Reporting Broken Links

Open an issue with the title "Broken link: [tool name]" and include:
- The broken URL
- The section where it appears
- A corrected URL if you know it

### Quality Guidelines

- **Verify links**: All links must be working and point to the correct resource
- **Avoid duplicates**: Check if the tool already exists before adding
- **Stay on topic**: Tools must be AI-powered and relevant to offensive security
- **Be concise**: Keep descriptions factual and brief

### Code of Conduct

- Be respectful and professional
- Focus on the quality of the resource, not the person
- No self-promotion without genuine value to the list

## Development

This is a markdown-only repository. No build steps required. Just edit `README.md` and verify that markdown renders correctly.
